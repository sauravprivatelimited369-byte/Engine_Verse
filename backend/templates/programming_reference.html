How to use a reference

Read the execution model first. Most of the remaining differences - copying, equality, null, concurrency, error handling - follow from how the runtime represents values. Then use the tables as a lookup: the syntax table for the exact rule, the library table by job, and the error table when something fails. The course paths teach in order; this page is the index you keep beside them.
