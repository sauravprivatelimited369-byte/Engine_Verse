Android — install the web app

  1. Open this site in Chrome.
  2. Tap the ⋮ menu, then Add to Home screen or Install app.
  3. Confirm. The icon appears on your home screen.

The web app uses this site's account and data. Offline access is limited to previously cached public pages; submissions and sign-in need a connection.
