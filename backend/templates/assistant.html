How this works

  • Your message goes to this site's server, which forwards it to an n8n workflow. The workflow's webhook address is never included in the page.
  • The reply is produced by a language model chosen by the site operator. It is generated text, not a quotation from a textbook.
  • {{ brand.site_name }} does not store the transcript. It records only small operational facts — that a question was asked, how long the answer took, and whether it succeeded — so the operator can see if the service is healthy.
  • Do not paste passwords, API keys, identity numbers or anything about another person. Questions are sent to the workflow's model provider.
