02 Spatial intuition · {{ models_3d_count }} WebGL scenes

Rotate the physics instead of guessing from a flat sketch

  • Knowledge-based XP: rewarded once on first genuine pass, never farmed

{# ==================================================== 11. HONEST FAQ #}

Straight answers

Questions learners ask first.

Meridian states what works, where your data lives, and what the platform is not — before you invest a semester in it.

About the project {{ icon("chevron", 13) }}

Is Meridian completely free and open source?

Yes. Meridian is MIT-licensed with no paywalls, ad networks, analytics trackers or third-party scripts. Every note, 3D model, practice question, coding problem and native app package is built openly from this repository.

How does code compile and run in the browser without a server?

On the static copy and mobile apps, each language runs inside an isolated Web Worker using pinned WebAssembly toolchains — Pyodide (CPython 3.12), Clang, OpenJDK with TeaVM, Roslyn, Rust Miri, GopherJS, TypeScript and SQLite — downloaded lazily the first time you pick that language.

Where is my study progress stored, and can I back it up?

{% if static_export %}On this static copy, streaks, XP, bookmarks and mistake notebooks stay in your browser’s local storage and can be exported or imported as a validated JSON file on Settings.{% else %}Signed-in accounts store progress in the server database across devices, and you can export or manage your data at any time in Settings.{% endif %}

Can I study offline on a phone or laptop?

Yes. Installing the PWA caches pages and 3D assets for offline reading, and the native iOS, macOS and Android apps bundle all {{ site.topics }} topics, {{ site.questions }} practice questions and the study planner right on your device.

Is Meridian an accredited university or qualification?

No. Seeded material is structured study scaffolding — unreviewed topics are clearly labelled as drafts — and Meridian completion certificates are verifiable records of work completed here, not academic degrees or professional licences.
