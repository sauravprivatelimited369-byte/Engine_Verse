How to use a sheet

  1. Read the problem statement on the page. Every problem ships its own worked examples and, if you want them, hints and a full editorial - nothing links out.
  2. Write the solution in the in-app editor and press Run against the sample tests first.
  3. Press Submit to run every test on the judge. Passing awards XP and marks the problem solved on the sheet.
  4. If a test fails, the verdict tells you which case failed and what was expected. XP is paid only on your first accepted solution, so it counts problems you actually passed — keep iterating until it passes.
