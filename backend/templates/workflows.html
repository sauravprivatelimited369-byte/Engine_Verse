Use the n8n export

  1. Import the downloaded JSON into your own n8n instance.
  2. Set the n8n variable engineverse_url to your {{ brand.site_name }} origin, without a trailing slash. Optionally set engineverse_topic to a published topic slug.
  3. If your app requires sign-in, configure an authenticated Cookie header/credential on the HTTP Request nodes. No cookie or credential is included in the export.
  4. Use the manual trigger. Each HTTP node calls an allowlisted GET operator and recomputes its dependencies read-only. The local dependency graph is shown above; the n8n transport calls run in sequence.

This is not a scheduler and does not send notifications. A revision plan does not mark cards reviewed; a placement plan does not certify interview readiness.
