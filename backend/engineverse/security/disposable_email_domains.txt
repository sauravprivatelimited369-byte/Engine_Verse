# Disposable / temporary email domains refused at sign-up.
#
# One lower-case domain per line; lines starting with # are ignored, and any
# line that is not a plain domain is skipped rather than trusted.
#
# Why the rule exists: an inbox that self-destructs in ten minutes cannot
# receive a password reset next semester, and "I lost that address as well" is
# a support request nobody can answer. The 6-digit code is the backstop - a
# burner only works if the person who made it can also read what landed in it.
#
# This list is deliberately short. It names only services whose entire product
# is a public or expiring inbox - no freemail provider, no university domain,
# no "alias" product that people use on purpose. A blocklist that is wrong in
# the other direction locks real learners out of the platform, which is far
# worse than letting a burner through. EngineVerse subscribes to nothing, so
# this file is the operator's knob: add what you actually see in your logs.
#
# Format: <service>, <service>, ... - keep it alphabetical for readability only.
